6. Form UX & Micro-Interactions

Contact Form Validation Engine

The contact form implements client-side validation prior to state submission:

  • Name: Required non-empty string
  • Email: Validated against standard RFC email regex (^[^\s@]+@[^\s@]+\.[^\s@]+$)
  • Subject: Required non-empty string
  • Message: Minimum threshold of 10 characters
  • Dynamic Error Removal: As soon as the user focuses and begins typing in an invalid field, the error indicator for that field clears immediately.
1-Click Clipboard Copy UX

Beside the primary email contact card, a dedicated copy button allows instant copying of karansingh2436nda@gmail.com:

  • Uses browser navigator.clipboard.writeText
  • Changes button state dynamically from grey copy icon to green checkmark
  • Displays "Copied to clipboard" feedback text for 2.5 seconds
  • Includes fallback alert in case clipboard API access is restricted
